### AI Visual Assistance System

An on-device visual assistance system designed to help people with visual impairments navigate complex environments.

The system combines object detection, monocular depth estimation, OCR, temporal tracking and contextual risk analysis.

- 📏 Monocular depth estimation
- 🔤 OCR with ML Kit
- 🧠 Contextual Environmental Risk Model
- 🔄 Temporal object tracking
- 🔊 Text-to-Speech alerts
- 📱 Android on-device inference
- ⚡ ONNX Runtime

**Stack**

`ML Kit` `Computer Vision` `Deep Learning`
